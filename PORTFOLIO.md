## Stack (CV)

- Flutter / Dart
- Bloc / Cubit
- Firebase Auth + Cloud Firestore
- REST (UmmahAPI)
- Geolocator + notifications locales (adhan / takbir)
- SharedPreferences, i18n FR / EN / AR
